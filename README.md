# داشبورد مدیریتی دفتر درآمد (tahlilfars2)

نسخه امن با احراز هویت و ذخیره‌سازی داده در Google Drive خصوصی.

## کارهای انجام‌شده

- فایل‌های `150.xlsx` و `1520.xlsx` به پوشه خصوصی Drive منتقل شدند.
- فایل `users.json` اولیه با حساب ادمین ایجاد شد.
- اسکریپت Backend (`Code.gs`) آماده است.
- کد فرانت برای ورود و بارگذاری امن داده آماده شده.

## حساب ادمین

- نام کاربری: `00`
- رمز عبور: `890630`

## مراحل بعدی

1. دیپلوی Code.gs به عنوان Web App در script.google.com
2. قرار دادن URL در `js/core/constants.js` (متغیر API_BASE)
3. پوش کامل کد (بدون فایل‌های اکسل)
