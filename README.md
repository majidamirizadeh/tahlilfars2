# داشبورد مدیریتی دفتر درآمد (tahlilfars2)

نسخه امن با احراز هویت و ذخیره‌سازی داده در Google Drive خصوصی.

## تغییرات نسبت به نسخه قبلی

- فایل‌های اکسل `150.xlsx` و `1520.xlsx` از مخزن عمومی حذف شده‌اند و در پوشه خصوصی Google Drive نگهداری می‌شوند.
- Backend مبتنی بر Google Apps Script برای احراز هویت و تحویل امن داده.
- صفحه ورود فارسی و راست‌چین.
- پنل مدیریت کاربران (فقط برای ادمین).
- رمزها به صورت Salted SHA-256 ذخیره می‌شوند؛ هیچ رمز خامی در کلاینت یا مخزن نیست.

## راه‌اندازی Backend

1. به [script.google.com](https://script.google.com) بروید و یک پروژه جدید بسازید.
2. محتوای فایل `Code.gs` (موجود در پوشه Drive یا artifacts) را در ادیتور جایگزین کنید.
3. Deploy → New deployment → Type: Web app
   - Execute as: Me
   - Who has access: Anyone
4. URL حاصل را کپی کنید و در `js/core/constants.js` به جای `YOUR_DEPLOYMENT_ID` قرار دهید.
5. فایل‌های اکسل باید در پوشه `01-source-excel` داخل Drive با نام دقیق `150.xlsx` و `1520.xlsx` باشند (قبلاً آپلود شده‌اند).

## حساب ادمین اولیه

- نام کاربری: `00`
- رمز عبور اولیه: `890630`

پس از ورود، از منوی تنظیمات می‌توانید کاربران جدید بسازید، رمز تغییر دهید یا حذف کنید.

## اجرای محلی / GitHub Pages

پروژه به صورت PWA روی GitHub Pages قابل استقرار است. پس از تنظیم `API_BASE`، Commit و Push کنید.

**مهم:** هیچ فایل اکسل واقعی یا JSON حاوی داده حساس را به مخزن اضافه نکنید.
