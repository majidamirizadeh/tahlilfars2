# داشبورد مدیریتی دفتر درآمد (tahlilfars2)

نسخهٔ امن با احراز هویت؛ داده‌ها (دو فایل Excel) فقط در Google Drive **خصوصی** نگهداری می‌شوند و از طریق Backend (Google Apps Script) و پس از ورود کاربر تحویل داده می‌شوند.

## معماری داده (سریع و خصوصی)

1. فایل‌های `150.xlsx` و `1520.xlsx` در پوشهٔ خصوصی `01-source-excel` در Drive هستند (هرگز در این مخزن یا هر جای عمومی نیستند).
2. هر بار فایل Excel جایگزین شد، کافی است **مدیر یک‌بار برنامه را باز کند**: مرورگر مدیر Excel را با همان پردازشگرهای موجود می‌خواند و خروجی را به‌صورت JSON فشرده (gzip) در پوشهٔ خصوصی Drive (`processed`) ذخیره می‌کند. نوشتن این فایل فقط با حساب مدیر ممکن است.
3. کاربران عادی فقط همان JSON کوچک را می‌گیرند؛ کتابخانهٔ XLSX و پردازش Excel برایشان اجرا نمی‌شود.
4. تا وقتی مدیر برنامه را باز نکرده، کاربران به‌طور خودکار به روش قبلی (خواندن مستقیم Excel) برمی‌گردند؛ پس داده هرگز قدیمی یا اشتباه نمایش داده نمی‌شود.
5. تشخیص تغییر فایل با «نسخهٔ واقعی فایل» (شناسه + زمان ویرایش + اندازه) انجام می‌شود، نه حدس.

محاسبات و تحلیل‌ها (processors / engines / dashboards) در این معماری دست‌نخورده‌اند؛ JSON فشرده فقط خروجی همان پردازشگرهاست و پیش از انتشار، برابری دقیق آن با خروجی اصلی بررسی می‌شود.

## امنیت

- فقط POST پذیرفته می‌شود؛ نام کاربری/رمز/توکن هرگز در URL نمی‌آید.
- رمزها با HMAC-SHA256 + salt + pepper (در Script Properties) ذخیره می‌شوند؛ حداقل طول رمز جدید ۸ کاراکتر.
- با تغییر رمز یا حذف کاربر، همهٔ نشست‌های قبلی او باطل می‌شود. عمر نشست ۶ ساعت است. قفل موقت پس از چند تلاش ناموفق.
- رمز پیش‌فرض در کد وجود ندارد؛ راه‌اندازی/بازنشانی رمز مدیر با Script Property انجام می‌شود (پایین را ببینید).
- دکمهٔ «خروج» نشست و داده‌های کش‌شدهٔ مرورگر (IndexedDB) را پاک می‌کند؛ نشست منقضی هم همین‌طور.
- `.gitignore` و `tools/check-no-data.mjs` از ورود فایل‌های Excel/CSV به مخزن جلوگیری می‌کنند. برای اجرای خودکار در CI، فایل‌های `docs/proposed-workflows/*.yml` را به `.github/workflows/` منتقل کنید.

## راه‌اندازی Backend

1. در [script.google.com](https://script.google.com) پروژه بسازید و محتوای `Code.gs` (نسخهٔ v2؛ در Drive) را جایگزین کنید.
2. در Project Settings → Script Properties یکی از این‌ها را بسازید:
   - راه‌اندازی اولیه (وقتی `users.json` وجود ندارد): `ADMIN_BOOTSTRAP_PASSWORD`
   - بازنشانی رمز مدیر اصلی: `ADMIN_RESET_PASSWORD` و سپس اجرای تابع `resetAdminPassword` از ویرایشگر (property پس از اجرا خودکار حذف می‌شود).
3. Deploy → Manage deployments → ویرایش Deployment فعلی → Version: New version (Execute as: Me، Access: Anyone).
4. اختیاری: اجرای یک‌بارهٔ `setupKeepWarm` برای گرم نگه داشتن کش کاربران/manifest.
5. آدرس Web App در `js/core/constants.js` (`API_BASE`) تنظیم شده است.
